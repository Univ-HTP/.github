# Univ-HTP .github Repository

Repositori publik ini berfungsi sebagai repositori konfigurasi profil dan berkas kesehatan komunitas (*community health files*) resmi untuk organisasi GitHub [**Universitas Hang Tuah Pekanbaru (Univ-HTP)**](https://github.com/Univ-HTP).

## Struktur Repositori

```text
.github/
├── profile/
│   ├── logo-uhtp.png       # Berkas aset logo resmi universitas
│   └── README.md           # Halaman utama profil organisasi GitHub Univ-HTP
├── README.md               # Dokumentasi repositori ini
└── SECURITY.md             # Kebijakan pelaporan kerentanan keamanan
```

## Tampilan Profil Organisasi

Halaman profil utama organisasi GitHub Univ-HTP dikelola melalui berkas [`profile/README.md`](profile/README.md). Setiap pembaruan informasi profil, tautan layanan digital, dan pembaruan arsitektur teknologi dilakukan melalui berkas tersebut.
